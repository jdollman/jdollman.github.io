Space probes

Mars Climate Orbiter, 1999. Lockheed Martin’s software gave thrust in imperial units; NASA’s expected metric. Lost.
Mars Polar Lander, 1999. When its legs unfolded on the way down, a sensor read the jolt as touchdown. It shut off its engine about 40 meters up.
Viking 1 lander, 1982. A faulty command sent from Earth. Contact was never restored.
An artificial superintelligence is like a space probe, in that we cannot test it in quite the same environment where it needs to work, and by default it is not retrievable or correctable once it rises high above us.
Humanity only gets one shot at the real test.
Eliezer Yudkowsky and Nate Soares
