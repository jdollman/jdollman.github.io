Digression: how an LLM thinks

Thinking in tokens

An LLM writes one token at a time. To produce each one, the model runs the whole text so far through its layers once: a forward pass.

One forward pass is a fixed amount of computation: a limited amount of “thinking”.

If a problem needs more computation than one pass can do, the model writes its intermediate results out as tokens and reads them back in: it thinks over many passes.

That written-out reasoning is the chain of thought (CoT).
